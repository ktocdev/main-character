Design system

The pieces the journal is built from, each rendered live from the app's own stylesheets. Nothing here is a mockup: if a page looks wrong, the app looks wrong too. (The one exception is the select's open list, which the browser draws outside the page; that page says so.) Every component also exports to Figma: see figma/components/.
