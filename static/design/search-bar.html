Search bar

One --bg-muted box holding everything search needs: the query, the mode, and the button. The input gives up its own well and border to the box, so the box takes the focus colour: it is the field. Enter submits; the button is there for pointers. Below about 28rem the controls wrap under the query.

States and modes

The mode is a soft toggle made a touch wider (1.8rem tall, .75rem sides). Off reads meaning: passages close to what you describe, ranked. On reads exact text: literal matches, newest first. The search button is a send pill.
