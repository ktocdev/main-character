Disclosure

Something that opens and closes, in two sizes. Large is a section: a native <details> whose header is the section's italic accent title, with the caret icon as its mark, turning from right to down when open. A run of them, hairline between each, is help's accordion. Native, so it opens from the keyboard and for find-in-page with nothing extra. Small folds a few controls away inside a sidebar or a menu. Both draw the same caret (static/icons/caret-right.svg).

Small · open and closed

A text button in the UI face with a caret, for showing and hiding a few controls inside a sidebar or a menu: the sidebar's "triage & recycling bin", and "find duplicates" in the clean up menu. It is a <button> with aria-expanded and aria-controls, not a <details>, so it can carry a count and live inside a menu that closes on its own. The caret turns from right to down when it opens; the CSS reads aria-expanded, so the script only sets that. Not in the Figma set yet.

button.disclosure-sm[.end][.active][aria-expanded][aria-controls]
  span.caret-icon      right when closed, turns down when open
  span                 the label
  span.count           optional: how many toggles inside are on, while closed

span.caret-icon.drop   the same icon on a menu trigger (clean up): down, turns up when open

  summary
    span.mark          the caret: right closed, turned down open
    span               the title
  div.disclosure-body  .8rem gap, indented 1.5rem
header
The body serif, italic, 1.3rem, --text-accent; 1.1rem above and below. The whole line is the target.
mark
The caret at .75rem in --text-muted, a mask in currentColor (as .caret-icon), centred on the title's first line however the title wraps. It turns in place, so the title never shifts.
body
A column, .8rem between blocks, indented 1.5rem so it hangs under the title, with 1.5rem below.
rule
A --border-default hairline under every section, open or closed.
Tokens

Title --text-accent; mark --text-muted; rule --border-default; type --font-body, --font-ui. In Figma: Disclosure, open, with title and body properties.
