# Icon licenses

The SVGs in this folder are taken from open icon sets, through
[Iconify](https://icon-sets.iconify.design/). Most are MIT; the caret is
CC BY-SA 4.0 and the dash ring Apache 2.0. Each file was renamed to what it stands for (`cake.svg`,
`cake-filled.svg`). Otherwise it is unchanged: the app draws it as a CSS mask
in the text colour. The design system's icons page
(`static/design/icons.html`) lists every icon with what uses it and its set.
